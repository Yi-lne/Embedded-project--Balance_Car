# STM32F103C8T6 两轮自平衡小车（Balance_Car）

## 项目简介

基于 STM32F103C8T6 的两轮自平衡小车：MPU6050 采集姿态，TB6612 驱动两个带编码器的直流减速电机，目标是实现直立、速度、转向三环控制以及蓝牙遥控与超声波防撞。项目包含两套独立实现（裸机定时调度版、FreeRTOS 多任务版）。目前已完成角度内环调试，速度环因编码器焊点/焊盘破损受阻，第三版 PCB 正在规划。

## 功能与进展

### 已实现

- 角度内环（直立环）：MPU6050 姿态解算 + PID 控制，完成基础调参并实现自平衡
- 姿态解算：互补滤波（裸机版本）/ 卡尔曼滤波（FreeRTOS 版本），上电陀螺仪零偏校准。
- 两套代码：裸机定时调度版、FreeRTOS 多任务版
- 电机与编码器：TB6612 双路 PWM + 方向控制，TIM3 / TIM4 提供正交编码器接口
- OLED 调试显示：姿态角、两轮速度、目标角度、PWM、I2C 错误计数等

### 暂未实现及原因

- **速度环 / 转向环**：速度值无法稳定获取。示波器检测两电机编码器 A/B 相信号正常，问题出在焊接上——由于反复焊接导致对应焊点及附近焊盘已破损、露出铺铜区域，不适合继续焊接，因此速度环调参暂停；转向环依赖两轮速度反馈，一并暂缓。
- **蓝牙遥控（HC-08）**：速度环未完成，车辆无法正常行驶与转向，蓝牙遥控暂时没有调试条件，被迫搁置。
- **超声波防撞（HC-SR04）**：与蓝牙同理，暂时搁置。
- **下一步**：通过第三版 PCB 重新设计编码器接口；之后再继续速度环、转向环、蓝牙和超声波功能。

## 控制结构

数据流：MPU6050 → 姿态角 → 角度内环（PID）→ PWM → TB6612 → 电机；编码器 → 速度外环 / 转向环（PI）→ 目标角度 / 差速 → 角度内环。

- 角度内环：以互补滤波 / 卡尔曼融合角为反馈，PID 计算平均 PWM；裸机版以误差差分作 D 项，FreeRTOS 版采用了陀螺角速度作 D 项
- 速度外环：以两轮平均速度为反馈，PI 输出目标角度；代码已实现，默认增益为 0，暂未调参
- 转向环：以两轮差速为反馈，PI 输出差分 PWM；同样默认关闭
- PWM 合成：左 = 平均 + 差分 / 2，右 = 平均 − 差分 / 2，再做限幅、死区补偿与方向控制

## 两套实现

| 项目 | 裸机版 `balance_car_program2` | FreeRTOS 版 `balance_car_program` |
| --- | --- | --- |
| 调度方式 | TIM2 1ms 中断置标志 + 主循环轮询 | 5 个任务 + 优先级抢占 |
| 姿态融合 | 互补滤波（α = 0.96） | 卡尔曼滤波（角度 + 陀螺零偏） |
| 角度环周期 | 5ms（200Hz） | 4ms（250Hz） |
| 速度 / 转向环周期 | 50ms（20Hz） | 10ms（100Hz） |
| MPU6050 读取 | I2C2 + DMA1_CH5，14 字节 | I2C2 阻塞读 |
| 任务间通信 | 全局标志 + 静态变量 | 队列邮箱（目标角度 / 差分 PWM） |
| 代码组织 | 前后台 + 标志位 | 任务拆分 + 队列解耦 |

### 裸机版

- TIM2 每 1ms 产生中断，按计数取模置位 5ms / 50ms / 91ms 标志；主循环轮询标志执行对应任务。
- 5ms：读取 DMA 收到的 MPU6050 数据，解算姿态角，执行角度环并更新 PWM。
- 50ms：读取两轮编码器计数并换算速度，执行速度环 / 转向环。
- 91ms：刷新 OLED。
- 上电静止 2s，连续采样 1000 次求陀螺零偏；姿态角用互补滤波融合。
- I2C 连续 2 次无应答时停电机、终止 DMA、重新初始化 I2C2 并重启接收，避免总线异常导致失控。

### FreeRTOS 版

- 5 个任务：姿态解算（4ms）、角度环（4ms）、编码器测速（10ms）、速度 / 转向环（10ms）、OLED（10ms）。
- 优先级：姿态与角度环 3，速度 / 转向 2，OLED 1，角度环的优先级最高，保证角度环的实时性。
- 卡尔曼滤波同时估计角度与陀螺零偏，加速度计角度由 `atan2(ax, az)` 得到。
- 速度 / 转向环算出的目标角度与差分 PWM 通过队列邮箱（覆盖写）传给角度环任务，避免共享变量竞争。

## PCB版本问题

### 第一版 PCB

第一版没有考虑到电源解耦问题，把电源线焊死在 PCB 上了，每次烧录程序都要插拔 5V 降压模块和 TB6612 模块，在一次操作中不小心把 TB6612 插反导致模块烧毁。

### 第二版 PCB（当前版本）

重新设计 PCB，把电源线解耦；但没有考虑防呆设计，电源改成用杜邦线连接。考虑到可能反接以及上电产生电压尖峰，在电源入口增加了防反接电路和 TVS 管。电机排线的焊点分布散乱，没有集成一个总接线端子，整体不够美观。使用中编码器排线的焊点及附近焊盘破损、露出铺铜，已无法继续焊接返修。

### MPU6050 安装问题

角度环自平衡调参时发现平衡零点总是不稳定。经过多次角度测试，定位到 MPU6050 模块本身安装不稳定：模块用排针 / 排母安装，排母松动或手误触都会导致模块位置偏移，已经测定的平衡点也会随之偏移。

### 第三版 PCB 规划

- 重新设计编码器接口（接线端子或加固焊盘），解决焊点/焊盘破损后无法返修的问题
- 重点设计电源输入解耦和防呆插入，避免反接与插拔问题
- 考虑把 MPU6050 芯片直接焊在 PCB 上，消除排母接触和位置偏移
- 改善电机排线布局，解决焊点分散、不美观等问题

## 后续计划

1. 设计第三版 PCB：重新设计编码器接口、电源输入解耦、防呆插入、MPU6050 焊板
2. 修复编码器焊接后继续速度环 / 转向环调参，再恢复蓝牙与超声波功能
